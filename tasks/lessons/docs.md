# Docs Lessons

- **Context:** Structuring the Progress section of the root `README.md`.
- **Mistake:** Used "Feature List" for finished technical setup (scaffold, health endpoint, repo conventions); the user meant it as the list of things the app can do for users (e.g. a QR code generator).
- **Correct Pattern:** "Feature List" holds user-facing capabilities only; technical groundwork goes under "Foundation".
